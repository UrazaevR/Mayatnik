# README проекта: «Зависимость периода колебаний маятника от амплитуды»

## Название проекта
**«Моделирование колебаний физического маятника и исследование зависимости периода от амплитуды»**

## Описание проекта

Приложение для численного моделирования движения физического маятника с учётом затухания (вязкое трение в воздухе). Программа позволяет:

- Решать дифференциальное уравнение движения методом Рунге-Кутты 4-го порядка
- Строить график зависимости амплитуды от времени
- Строить график зависимости периода от амплитуды
- Учитывать реальное затухание на основе параметров маятника (закон Стокса)

Графический интерфейс реализован на PyQt6.

## Физическая модель

### Уравнение движения

\[
J \ddot{\varphi} = -m g d \sin\varphi - b \dot{\varphi}
\]

где:
- \( J = m d^2 \) — момент инерции
- \( \varphi \) — угол отклонения
- \( m \) — масса маятника
- \( g \) — ускорение свободного падения
- \( d \) — длина маятника
- \( b = 6 \pi \eta R d^2 \) — коэффициент момента сил трения (закон Стокса)
- \( \eta = 1.81 \times 10^{-5} \) Па·с — вязкость воздуха
- \( R \) — радиус груза

### Определение амплитуды и периода

- Амплитуда — локальные максимумы угла с параболической интерполяцией
- Период — разница между соседними моментами максимумов

## Установка и запуск

### Требования

- Python 3.8 или выше

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск программы
```bash
python main.py
```

## Использование программы

### Входные параметры

| Параметр | Описание | Пример |
|----------|----------|--------|
| Время окончания эксперимента | длительность моделирования (с) | 500 |
| Ускорение свободного падения g | м/с² | 9.81 |
| Шаг по времени h | с | 0.001 |
| Масса маятника m | кг | 2.4 |
| Длина маятника d | м | 0.95 |
| Радиус маятника R | м | 0.05 |
| Начальный угол отклонения | градусы | 30 |
| Начальная скорость | рад/с | 0 |
| Использовать реальную beta | галочка | при включении — затухание по Стоксу, иначе β = 0.04 |

### Управление

- **Рассчитать** — запуск моделирования
- **Стоп** — остановка расчёта

### Выходные данные

1. **Левый график** — амплитуда (градусы) от времени (секунды)
2. **Правый график** — период (секунды) от амплитуды (градусы)

Графики интерактивны: панель навигации позволяет приближать, перемещать, сохранять изображения.
